## Step

1. Create a `local.properties` file inside the android folder with your Android SDK location, for example:

```
sdk.dir=/Users/<user-name>/Library/Android/sdk
```

2. For iOS, run:
```
cd ios
pod install
```

## Run

```
flutter run
```
